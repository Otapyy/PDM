1 - O ciclo de vida de uma activity se refere as etapas que uma aplicação mobile pode se encontrar durante sua execução, por exemplo, o create é uma dessas etapas, etapa essa que acontece quando a activity é iniciada,
quando desenvolvemos projetos mobile queremos que elementos apareçam na tela, então, colocamos esses elementos no create, para quando a activity for criada os elementos ja serão criados juntos, tambem existem outras
etapas do ciclo de vida, elas são responsaveis por pausar o app, fechar ele etc.

2 - resorces dentro de um projeto android soa recursos extras as "funcionalidades", muitas vezes ligadas com a parte visual, guarda informações de configurações gerais do projeto e tambem contem as telas onde o usuario navega.
Activitys seriam como telas, uma activity contem determinada função e nela é executada o codigo java em si que é responsavel pela funcionalidade do projeto.
